# 后殿镜头

00为用户确认并要求保存的全景母版。01—08为新生成待验收镜头，均为空场景。

| 编号 | 用途 |
| --- | --- |
| 01 | 梳妆台正面镜区近景，对镜试冠与镜中表情 |
| 02 | 梳妆区侧面，女子坐姿及男子站姿摘冠动作 |
| 03 | 台面中央操作区特写，后续倒扣凤冠 |
| 04 | 梳妆区至床榻空间关系 |
| 05 | 床榻正面中景 |
| 06 | 床边向入口反打 |
| 07 | 窗边侧廊看全室 |
| 08 | 高位斜俯，交代人物调度空间 |

01—03为梳妆重点镜头，当前未添加人物、凤冠或手部。实际镜头制作需按男女主人设核对坐姿与站姿尺度、摘冠手臂空间及镜中人脸；镜面为生成的空房反射，未经过光学几何校准，不能视为最终正确反射。01镜框与摆件较母版存在变化，02景别仍偏宽；台面反光、跨视角家具尺寸、灯具数量与入口墙新设计均待验收。必要时对镜面与人物分别制作图层。横版底图不等于9:16剧情镜头已完成适配。
